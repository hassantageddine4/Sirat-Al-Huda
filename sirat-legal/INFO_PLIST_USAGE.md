# Info.plist usage descriptions — REQUIRED for App Store approval

When you request a permission, iOS shows the system popup with a string
**you provide** in your `Info.plist`. Apple rejects apps that request
sensitive permissions without a descriptive usage string explaining why.

Add the following keys to `ios/App/App/Info.plist`. If the key already
exists, replace the placeholder string with the one below.

---

## 1. Location

```xml
<key>NSLocationWhenInUseUsageDescription</key>
<string>Sirat uses your location to calculate accurate prayer times for your area and to point the qibla in the right direction. Your location stays on your device.</string>
```

If you ever need background location (for things like prayer reminders that
re-trigger when you cross time-zone lines), add:

```xml
<key>NSLocationAlwaysAndWhenInUseUsageDescription</key>
<string>Sirat uses your location only when needed for prayer times and qibla direction.</string>
```

Do NOT add this key unless you actually use background location — Apple will
ask you to justify it during review.

---

## 2. Microphone

```xml
<key>NSMicrophoneUsageDescription</key>
<string>Sirat uses the microphone for the recitation practice feature, so you can compare your recitation to the Qur'an. Audio is processed on your device.</string>
```

---

## 3. Speech Recognition

```xml
<key>NSSpeechRecognitionUsageDescription</key>
<string>Sirat uses speech recognition to help you practice Qur'an recitation. Speech is processed by iOS and not stored by Sirat.</string>
```

This is a separate permission from microphone on iOS.

---

## 4. Camera (only if you actually use it)

```xml
<key>NSCameraUsageDescription</key>
<string>Sirat uses the camera so you can take a profile photo.</string>
```

---

## 5. Photo Library (only if you let users pick from photos)

```xml
<key>NSPhotoLibraryUsageDescription</key>
<string>Sirat needs access to your photo library so you can choose a profile picture.</string>
```

---

## 6. Push / Local Notifications

Notifications do **not** require a usage description string in Info.plist — the
permission popup is generated by `UNUserNotificationCenter`. Just make sure
you call `requestPermissions()` from `@capacitor/local-notifications`
contextually (e.g. after the user enables prayer reminders), not on app launch.

---

## How to apply

1. Open `ios/App/App/Info.plist` in Xcode (right-click → Open As → Source Code)
2. Paste the keys above inside the top-level `<dict>`
3. Save and run `npx cap sync ios`

---

## App Store privacy nutrition label

When you submit to App Store Connect, Apple asks you to declare what data is
collected. Based on the Privacy Policy, here's the answer:

| Data type        | Collected? | Linked to user? | Used for tracking? | Purpose |
|------------------|-----------|-----------------|---------------------|---------|
| Email Address    | Yes       | Yes             | No                  | Account |
| User ID          | Yes       | Yes             | No                  | Authentication |
| Coarse Location  | No (on-device only) | — | — | — |
| Audio            | No        | —               | —                   | — |
| Crash Data       | Yes (if you enable it) | No  | No | Diagnostics |

If you add analytics or any third-party SDK later, update this declaration.

## Required plugins

Install before building:

```bash
npm install @capacitor/geolocation @capacitor/local-notifications @capacitor/browser @capacitor/app
npm install @capacitor-community/speech-recognition
# Optional, only if you add features that use them:
# npm install @capacitor/camera
```

After install:

```bash
npx cap sync ios
```
